# ADR 索引

设计决策记录采用**单一编号序列**：文件名 `NNNN-<slug>.md`，编号全仓唯一、单调递增、允许缺口、不补号，与领域无关——领域归属由每篇顶部「领域/适用范围」标注声明。新增决策取现有最大编号 +1 追加；编号重组的历史映射见 ADR-0022。

## 阅读规则

- 处理 `packages/` 下某 workspace 的内容前，阅读本索引中适用范围覆盖该 workspace 的 ADR；消费规则见 `docs/agents/domain.md`。
- 输出与某篇 ADR 冲突时，显式引用其编号提出，不静默覆盖。
