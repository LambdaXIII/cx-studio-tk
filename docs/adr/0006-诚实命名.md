# 组件命名必须反映实际行为

> 领域：cx-wealthy · 适用范围：cx-wealthy

组件命名必须反映实际行为，名实不符会误导使用方对 API 契约的预期。列布局组件命名为 `MaxColumnsLayout`（固定最大列数 + 平均宽度），而非暗示动态测量的名字——除非真正实现了基于内容宽度的动态列数计算。

## Considered Options

- **在初始版本直接做真正的动态列测量**：真正基于 `Measurement.get` 的动态测量复杂度被低估，且单点需求不足以验证必要性。诚实命名（`MaxColumnsLayout`）比名实不符更好。

## Consequences

- `MaxColumnsLayout` 的 API 契约明确：固定最大列数 + 平均宽度。
- 若未来出现第二个真实使用场景需要动态列数，再实现并另行命名，而非改挂旧名。
