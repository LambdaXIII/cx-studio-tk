# Triage 标签

技能以五个规范 triage 角色表达概念。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| 技能角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分描述，可交给 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某个角色（如"应用 AFK-ready 的 triage 标签"）时，使用本表右列对应的标签字符串。

标签词汇变化时直接编辑本文件右列。
