# 时间域与开放库原则

时间域（CxTime/Timebase/TimeRange/timecode）是多年积累的核心资产：直接兼容工业标准（时间码）、毫秒级精度为刻意设计、将来有广泛用途（时间线解析等）。决定：禁止以"零引用"为由删除时间域代码；同时 cx-studio 是开放功能库，仓库内零引用 ≠ 死代码（外部消费者不可见），删除公开 API 需作者确认不可用/未完成/未文档化。

## Consequences

- 时间域代码即使仓库内零引用也必须保留，不得据此删除
- 仓库内引用数不能作为判定 cx-studio 代码为死代码的唯一依据
- 删除任何公开 API 前必须先获得作者确认（不可用/未完成/未文档化）
