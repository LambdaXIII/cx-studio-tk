# subtitler 使用指南

> *字幕格式互转——只搬运，不编辑。*

## 简介

subtitler 把字幕文件从一种格式转换成另一种格式。它只做格式搬运：读出全部字幕条目、按时间组织，再以目标格式写出——不改写文本、不修剪时间、不重排内容。源格式表达不了的字段保持为空，不会被凭空生成。

```bash
subtitler movie.srt movie.ttml
```

## 基本用法

```
subtitler INPUT OUTPUT
```

| 参数 | 说明 |
|---|---|
| `INPUT` | 输入字幕文件，格式按扩展名识别 |
| `OUTPUT` | 输出字幕文件，格式按扩展名识别 |

- 源与目标为同一格式也允许（往返转换）；
- 未识别的扩展名报错中止，不产生任何输出。

## 支持的格式

| 格式 | 扩展名 |
|---|---|
| SubRip（SRT） | `.srt` |
| TTML | `.ttml` / `.xml` / `.dfxp` |
| CSV | `.csv` |

三种格式都可作源与目标，可任意互转；多行台词在格式之间保持换行等价。

## 输出文件

通常产出单个输出文件，路径即 `OUTPUT`。当来源含交叠条目而目标格式不允许交叠时（见下节），输出会拆分为多个文件，命名为「目标文件名 + `.part<k>`」（k 从 1 起，按输出顺序），目录与扩展名跟随 `OUTPUT`：

```bash
subtitler movie.ttml movie.srt   # 交叠来源 → movie.part1.srt、movie.part2.srt ...
```

写出前会一次性预检全部目标路径：任一目标（含派生的 `.part<k>` 路径）已存在即报错中止，不写出任何文件、也不覆盖既有文件。

## 交叠与拆分

- 交叠（两条字幕的时间区间部分重合）在模型中是合法状态；
- 导出允许交叠的格式（TTML / CSV）时原样保留，产出单个文件；
- 导出不允许交叠的格式（SRT）时自动拆分：按时间扫描分组，同一组内不交叠，全部条目无丢失；分组不追求文件数最少，但保证合法；
- 端点相触（如 `[0,5s]` 与 `[5,10s]`）不构成交叠，不会因此拆分。

## CSV 表头契约

字幕 CSV 没有通用标准，本工具自定表头契约：保留列必须依序位于表头最前。

```
start,end,text,speaker
```

| 列 | 含义 |
|---|---|
| `start` / `end` | 起止时间，毫秒精度的 `HH:MM:SS.mmm` |
| `text` | 字幕文本；多行台词以 RFC 4180 引号内的换行表达 |
| `speaker` | 说话人；空单元格表示无说话人 |
| 其余列 | 扩展列，列名即条目扩展字段的键，原样互映射；导出时取全部条目扩展键的并集，缺失记空单元格 |

表头不符、时间语法错误、扩展列与保留列同名都会报错中止。

