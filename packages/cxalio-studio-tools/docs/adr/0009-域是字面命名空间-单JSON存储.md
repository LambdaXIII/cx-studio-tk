# 域是字面命名空间，单 JSON 存储

## 决策

cx-note 的「域」是**字面命名空间**：形如 `/a/b` 的纯字符串，仅用作条目归属的组织单位，不映射到文件系统目录结构。域身份判定大小写不敏感，存储保留首次出现的原始字面（后续不同大小写的访问映射到同域但不改写字面）。全部条目存入**单个 JSON 文件**（`~/.config/cx-studio/CxNote/notes.json`，走 ConfigManager 惯例路径），每次保存整文件原子重写（临时文件 + rename）。

## 理由

cx-note 的域既要由 cwd 自动推导，又要允许用户自拟任意名字（如 `/生活琐事/午餐清单`）。若把域映射为目录结构，斜杠会变成目录分隔符，中文/特殊字符域需要转义，子树列举退化为目录扫描，Windows 路径字符集还会反向约束域字面。字面命名空间让域树纯逻辑存在——子树列举和保存时顺带的超龄清理都只是一次内存遍历。

## Considered Options

- **每域一文件**（域字面映射磁盘目录）：被否——斜杠参与文件系统、域名字符受限、跨域列举要扫目录树。
- **SQLite**：被否——对几百条短文本过重，且数据库不可直接人工翻看，调试不如 JSON 直观。
- **单 JSON 文件**：选定——条目都是短字符串，总量小，人可读，跨域操作一次内存遍历完成。

## Consequences

- Windows 去盘符 + 大小写不敏感身份的自然后果：跨盘符（`C:\work\proj` 与 `D:\work\proj`）、HOME 内外同字面的路径会**合并为同域**。这是设计后果，不是缺陷。
- 自动清理只清当前域、尽力而为（类似文件信息缓存，不做全库扫描）：未回访域的超龄已完成条目会滞留，属预期行为。
