# Spec Delta

## Purpose

定义字幕模型的行为契约：片段结构与预置字段、由开始时间定义的时序语义、集合作为片段集合的有序维持、交叠的合法性、作品的多集合结构。模型不认识任何字幕格式。

## ADDED Requirements

### Requirement: 片段由时间范围、台词、说话人与扩展位构成

每个字幕片段 MUST 携带：一个时间范围（复用 `cx_studio.core` 的 `TimeRange`——以 start + duration 存储、end 派生）、台词内容、说话人、以及开放扩展位。时间范围之外，片段 MUST NOT 冗余存储开始时间或时长。说话人为可空字段：无说话人语法的来源格式（如 SRT、TTML）导入时为空值。扩展位 MUST 能容纳任意格式附加字段（如样式、位置、语言标记）；模型 MUST NOT 解释、校验或约束扩展位内容。

#### Scenario: 时长由时间范围导出

- **WHEN** 片段的时间范围为起 10s、止 15s
- **THEN** 时长为 5s，且不存在与之重复存储的时长状态

#### Scenario: 扩展位随片段携带

- **WHEN** 导入的片段带有其来源格式的附加信息（如字号）
- **THEN** 该信息经扩展位随片段流转，模型不对其做任何解释或校验

### Requirement: 时序由片段的开始时间定义

片段之间的先后顺序 MUST 由开始时间定义；顺序是片段自身的属性，不是容器赋予的排列。交叠 MUST NOT 产生排序歧义：两个交叠片段的先后由其开始时间的大小关系唯一确定。

#### Scenario: 交叠片段的先后

- **WHEN** 片段 A（起 10s、止 25s）与片段 B（起 18s、止 30s）共存
- **THEN** A 先于 B（10s < 18s），与区间交叠与否无关

### Requirement: 集合是片段的集合，添加时按开始时间维持有序

集合 MUST 是片段的集合。添加片段 MUST 按其开始时间插入到确定位置，使集合在任意读取时刻处于按开始时间非降序状态；顺序 MUST 在添加时确立，而非读取时临时计算。开始时间相同的片段 MUST 稳定落位（既有片段相对次序不被新插入破坏）。

#### Scenario: 读取恒为时序

- **WHEN** 以任意顺序向集合添加片段后遍历集合
- **THEN** 遍历结果按开始时间非降序，且读取路径上不存在排序步骤

#### Scenario: 相同开始时间的稳定插入

- **WHEN** 向已含开始时间 5s 片段的集合再添加一个开始时间 5s 的片段
- **THEN** 添加成功，新片段落位确定，不扰动既有片段的相对次序

### Requirement: 交叠是集合的合法状态

集合 MUST NOT 因片段交叠而校验、拒绝、告警或改写片段。交叠是模型层面的正常状态，不是需要修复的异常。

#### Scenario: 交叠片段正常入集

- **WHEN** 向集合添加与既有片段时间交叠的片段
- **THEN** 添加成功，两个片段原样共存于集合，无告警、无改写

### Requirement: 作品由显式组织的多个集合构成

作品 MUST 是片段集合（×N）的组合。每个集合的归属 MUST 显式确定（手动划分，或导入时按来源文件/序列解析得出），MUST NOT 存在隐式推断、合并或拆分。模型 MUST NOT 引用「序列」概念——序列属于格式侧。

#### Scenario: 显式多集合

- **WHEN** 将交叠片段手动分开到不同集合，或从多个来源文件导入
- **THEN** 作品包含对应的多个集合；模型不合并未作声明关系的集合，也不推断集合间的关系

#### Scenario: 模型层不出现序列概念

- **WHEN** 以模型层公开接口执行任何操作（添加、遍历、组合）
- **THEN** 接口的参数与返回值只涉及片段、集合、作品，不存在序列类型、序号字段或格式特定概念
