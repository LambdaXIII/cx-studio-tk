# Spec Delta — cxnote

## MODIFIED Requirements

### Requirement: list 的平铺域块与折叠展示

人读列表 MUST 以平铺域块展示：每域一个标题行，其下为该域的条目块；域块间以空行分隔，MUST NOT 使用树状缩进或装饰符号。默认 MUST 折叠：当前域条目全显，下级域仅显示标题行；`--full` 时每个下级域标题下接各自条目块。当前域标题 MUST 只显示域名字（末段），根域显示固定标签 `GLOBAL`；下级域标题显示相对当前域的字面并附该域自身条目数（不含孙级）。域标题 MUST 以主题样式表中登记的专属样式名呈现，渲染代码 MUST NOT 内联样式属性。当前工作域非根时，列表 MUST NOT 出现绝对路径。列表分组 MUST 当前域组在前、其余按域身份排序，组内按创建时间升序。已取消条目 MUST 照常显示并以红色加删除线标识（标号与内容），已完成条目徽章随行变暗。当前域无条目时 MUST 输出空态提示，不静默。

#### Scenario: 默认折叠与展开

- **WHEN** 当前域及其下级域各有条目，分别以默认参数与 `--full` 执行 `list`
- **THEN** 默认输出中下级域仅有标题行；`--full` 输出中下级域条目块全部展开

#### Scenario: 标题相对化

- **WHEN** 当前域为 `/a/b`，其下级域 `/a/b/c` 有 2 条条目
- **THEN** 列表中当前域标题显示 `b`，下级域标题显示 `/c (2)`，不出现 `/a/b` 全路径

#### Scenario: 根域标签

- **WHEN** 以 `-g` 执行 `list`
- **THEN** 当前域标题显示 `GLOBAL`

#### Scenario: 已取消条目的可见与弱化

- **WHEN** 列表或回显中存在已取消条目
- **THEN** 该条目以 `[-]` 标号正常显示，标号与内容以红色加删除线标识；文本定位仍可命中它

### Requirement: 即将被清理的条目标记

**即将被清理**指本次运行的收尾阶段会因超龄而被清除的条目——仍留在工作集中、落在清理作用域（当前工作域及其下级域）内、且满足「终态条目超龄自动清理」所列清除条件者。被本次操作取走的条目（`erase` / `clear` 的输出）不在其列：收尾不会再清除它们。该判定 MUST 按当前工作集与本次运行生效的保留天数即时计算，MUST NOT 固化进条目、MUST NOT 写入存储。

- 人读呈现：即将被清理条目的条目块 MUST 带一个词形标记（文案「即将被清理」），且条目本体（标号与内容）MUST 以红色加删除线呈现——红色标识覆盖状态弱化样式（已完成条目不再变暗）。
- `--json` 呈现：即将被清理的条目对象 MUST 携带 `expiring` 键（真值）。

#### Scenario: 列表中标出即将被清理的条目

- **WHEN** 当前域内 3 条条目中 1 条为即将被清理
- **THEN** 该条目的条目块带「即将被清理」标记且本体红色加删除线，另两条不带标记、样式不变

#### Scenario: 离开终态后标记消失

- **WHEN** 对一条即将被清理的条目执行 `reset`（转回待办）
- **THEN** 本次运行的收尾不清除它，呈现中也不带标记，本体恢复待办样式

## ADDED Requirements

### Requirement: 被删除条目以红色回显

凡已从工作集取走、但仍以条目块展示的条目——`erase` / `clear` 的确认回显与收尾超龄清理的报告——其标号与内容 MUST 以红色加删除线呈现；状态标号 MUST 仍为取走前状态的标号（如对已完成条目 `erase` 仍显示 `[x]`）。三种消亡语境（已取消、即将被清理、已被删除）的红色 MUST 同源一致：同一语义样式，MUST NOT 按场景区分色相或强度。

#### Scenario: erase 回显的红色标识

- **WHEN** 人读模式对一条待办条目执行 `erase`
- **THEN** 确认行之下的回显条目块标号为 `[ ]`，标号与内容以红色加删除线呈现

#### Scenario: 清理报告的红色标识

- **WHEN** 收尾超龄清理清除了已完成与已取消条目并打印报告
- **THEN** 报告中每个条目块的标号与内容以红色加删除线呈现，标号保持各自取走前状态
