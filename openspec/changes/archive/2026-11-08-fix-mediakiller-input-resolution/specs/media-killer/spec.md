# Spec Delta

## Purpose

定义 media_killer CLI（基于 FFmpeg 的批量转码工具）输入侧的现行行为契约：原始输入字符串如何解析为路径集合（含目录与项目文件的展开、查重与排序），路径集合如何提炼为预设文件与源文件并组装为转码任务；同时约定各环节的失败形态——什么报错中止、什么是合法的静默排除。

## ADDED Requirements

### Requirement: 输入解析将原始输入解析为路径集合

输入解析是输入侧的第一环节：它将全部原始输入字符串解析为一份**路径集合**——集合由存在的文件路径构成，每条输入基于 CWD 解析为绝对路径。不存在的输入若无扩展名，MUST 先尝试追加 `.toml` 后缀（补全命中的必须是文件）再判定；仍不存在的 MUST 报错中止并指明该输入，MUST NOT 静默跳过。带扩展名的缺失输入 MUST 直接报错，MUST NOT 被补全改写为其它路径。原始输入路径的可读性 MUST 尽力检测，检出不可读时 MUST 报错中止并指明路径；未检出时不静默——由读取该文件的环节以指明该路径的报错或失败呈现。路径集合 MUST 按绝对路径查重并确定性地排序。输入解析 MUST NOT 因预设的存在与否、路径是否属于源后缀而改变解析行为；它仅有的格式感知是缺失输入的 `.toml` 补全与项目文件类型识别（见下条），存在的目录永远按目录展开。

#### Scenario: 目录输入被展开而非误判为预设

- **WHEN** 输入包含一个无扩展名的目录
- **THEN** 该目录进入展开并产出其中的文件路径，不出现「加载预设文件失败」类错误

#### Scenario: 不存在的输入报错中止

- **WHEN** 输入路径不存在，且补全 `.toml` 后缀后仍不存在
- **THEN** 报错中止并指明该输入路径，不静默跳过

#### Scenario: 补全仅对不存在的路径生效

- **WHEN** 输入为无扩展名的 `preset`，`preset` 本体不存在，同目录存在 `preset.toml`
- **THEN** 该输入按 `preset.toml` 解析

#### Scenario: 带扩展名的缺失输入不触发补全

- **WHEN** 输入 `clip.mp4` 在文件系统中不存在（无论同目录是否存在 `clip.toml`）
- **THEN** 报错中止并指明该输入，不解析为任何 `.toml` 路径

#### Scenario: 不可读路径报错中止

- **WHEN** 输入路径存在但不可读（如权限不足）
- **THEN** 报错中止并指明该路径（尽力检测：未检出时不静默，由读取该文件的环节以指明路径的报错或失败呈现）

#### Scenario: 重复输入只保留一份

- **WHEN** 同一文件经多条输入（直接给出或经目录展开）重复进入解析
- **THEN** 路径集合中只保留一份

### Requirement: 目录与项目文件在输入解析中展开

目录输入 MUST 被递归展开为其下全部文件的路径，展开 MUST NOT 依据任何源后缀预过滤。**作为输入给出的**项目文件（EDL `.edl`、Fcp7XML `.xml`、FCPXML `.fcpxml`、Resolve CSV `.csv`、纯文本路径列表 `.txt`/`.ps1`/`.sh`）MUST 交由 media_scout 的 Inspector 链解析出其中引用的媒体路径；引用路径为相对路径时 MUST 基于项目文件自身所在目录解析。类型与后缀判定均大小写不敏感。解析过程中抛出的异常 MUST 报错中止并指明该项目文件；无法识别或不可解码的项目文件产出零条引用（合法静默排除）。项目文件引用了不存在的媒体路径时，该引用被静默跳过、不报错（合法排除——项目文件可能引用未就绪的素材）。项目文件引用只做存在性过滤，后缀筛选属于资源提炼环节。目录展开产出的全部文件按普通文件路径进入路径集合，MUST NOT 被再次解析为项目文件。

#### Scenario: 目录递归展开

- **WHEN** 输入目录的子目录中嵌套媒体文件
- **THEN** 嵌套文件全部进入路径集合

#### Scenario: 目录内的 toml 进入路径集合

- **WHEN** 输入目录中包含 `.toml` 文件
- **THEN** 该文件进入路径集合，由资源提炼环节提取为预设文件

#### Scenario: 项目文件内相对路径基于项目文件位置解析

- **WHEN** 一个 EDL 文件引用相对媒体路径
- **THEN** 该路径基于此 EDL 所在目录解析为绝对路径

#### Scenario: 项目文件引用缺失素材被静默跳过

- **WHEN** 项目文件引用的媒体路径在文件系统中不存在
- **THEN** 该引用不进入路径集合且不报错

### Requirement: 资源提炼将路径集合分为预设与源文件

资源提炼是输入侧的第二环节，消费路径集合，对原始输入形态一无所知。它 MUST 将路径集合中所有 `.toml` 文件加载为预设文件（后缀比较大小写不敏感）：任一预设加载失败（TOML 语法、结构或标签检查不通过）MUST 报错中止并指明文件与原因，MUST NOT 部分采用其余预设。路径集合中不存在任何 `.toml` 时 MUST 报错中止（未提供预设文件）。其余路径 MUST 依据全部预设合并的源后缀集合过滤为源文件（比较大小写不敏感）；不符合源后缀的文件——包括无扩展名文件——被排除且不报错（合法排除：媒体目录通常混有非媒体文件，既有后缀过滤体系即承担此责）。

#### Scenario: toml 文件被提取为预设

- **WHEN** 路径集合包含结构与标签均有效的 `.toml` 文件
- **THEN** 它被加载为预设文件，参与任务组装

#### Scenario: 无效预设报错中止

- **WHEN** 路径集合中的某个 `.toml` 缺少必需节或含非法标签
- **THEN** 报错中止并指明该文件与原因，不生成任何任务

#### Scenario: 未提供预设报错中止

- **WHEN** 路径集合中不含任何 `.toml` 文件
- **THEN** 报错中止（未提供任何预设文件）

#### Scenario: 非媒体文件被静默排除

- **WHEN** 路径集合包含扩展名不在合并源后缀集合中的文件（如 `.nfo`）
- **THEN** 该文件被排除、不成为源文件，且不报错

#### Scenario: 有预设无源

- **WHEN** 路径集合含有效预设文件，但过滤后不剩任何源文件
- **THEN** 不报错，提示零任务并正常退出

### Requirement: 任务组装将预设与源文件组合为任务

任务组装 MUST 为每个预设与每个源文件生成转码任务（预设与源的全组合）。任务身份由（源文件路径，预设 id）构成：`--continue` 恢复的任务与新生成的任务合并后 MUST 全量排序去重，任何来源的重复任务——包括不同预设文件携带相同 preset_id 的——只保留一份。

#### Scenario: 预设与源的全组合

- **WHEN** 提炼出 2 个 preset_id 互异的预设与 3 个源文件
- **THEN** 生成 6 个任务

#### Scenario: 相同预设 id 的任务折叠

- **WHEN** 两个预设文件携带相同的 preset_id，各自与同一源文件生成任务
- **THEN** 去重后只保留一份

#### Scenario: continue 恢复的重复任务去重

- **WHEN** `--continue` 恢复的任务与本次生成的任务指向同一预设与源
- **THEN** 合并去重后只保留一份
